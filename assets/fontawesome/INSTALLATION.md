# Font Awesome Installation

## Manuelle Installation erforderlich

Da der automatische Download nicht möglich war, müssen Sie Font Awesome manuell installieren:

### Schritt 1: Download
1. Gehen Sie zu: https://fontawesome.com/download
2. Laden Sie **Font Awesome Free for the Web** herunter
3. Entpacken Sie die ZIP-Datei

### Schritt 2: Dateien kopieren
Kopieren Sie folgende Ordner aus dem entpackten Archiv in dieses Verzeichnis (`/assets/fontawesome/`):

- `css/` - alle CSS-Dateien
- `webfonts/` - alle Font-Dateien

### Schritt 3: Fertig!
Die Integration ist bereits in `functions.php` vorbereitet. Sobald die Dateien kopiert sind, funktioniert Font Awesome automatisch.

## Verwendung

Nach der Installation können Sie Font Awesome Icons überall verwenden:

```html
<i class="fa-solid fa-heart"></i>
<i class="fa-regular fa-star"></i>
<i class="fa-brands fa-github"></i>
```

Mehr Infos: https://fontawesome.com/docs
