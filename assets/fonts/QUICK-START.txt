   → Modern Browsers

2. Öffnen Sie: https://gwfh.mranftl.com/fonts/figtree
   → Wählen: 400, 500, 600
   → Modern Browsers
   → Download

3. Kopieren Sie die WOFF2-Dateien:
   outfit/*.woff2  → wp-content/themes/physiotherapy-pro/assets/fonts/outfit/
   figtree/*.woff2 → wp-content/themes/physiotherapy-pro/assets/fonts/figtree/

4. Cache leeren (Browser + WordPress)

5. FERTIG! ✅
